# Saurav Mukherjee — Portfolio

A motion-led portfolio for Saurav Mukherjee, an AI engineer and product builder working across production AI, agentic systems, cloud platforms, and developer communities.

**Live site:** [sauravmukherjee.in](https://sauravmukherjee.in/)

**Contact:** [sauravmukherjee928@gmail.com](mailto:sauravmukherjee928@gmail.com)

## What is inside

- An interactive hero built around Saurav's AI engineering practice
- Field notes with optimized video and image media
- Product case studies for OpsWeave, VerdaTrace, and HealthAI Agent Lab
- A project modal with responsive mobile product previews
- Professional experience across EY, Mercor, SMIIT, CodeIN, and ConnectBud
- A capability workbench connecting skills to real work
- Public GitHub activity, résumé access, and contact links
- Responsive layouts, mobile card stacks, smooth scrolling, and reduced-motion support

## Technology

- Next.js 16 and React 19
- TypeScript
- Motion for React
- Lenis smooth scrolling
- Lucide icons and custom lightweight SVG marks
- Optimized AVIF, WebP, and MP4 assets

## Run locally

```bash
npm install
npm run dev
```

The development server runs at [http://localhost:3001](http://localhost:3001).

Create an optimized production build with:

```bash
npm run build
npm start
```

## Project structure

```text
app/                 Next.js application and visual system
public/assets/       Optimized portfolio media, logos, and project captures
public/*.pdf         Public résumé
```
